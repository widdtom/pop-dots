# Pop Dots

A calm, Two Dots-style connecting game for young children. No timer, no losing, no ads — tap **Stop** when you're done and the score is kept.

- Join 2+ dots of the same colour (1 point each); long lines earn bonuses
- Close a square to pop every dot of that colour; trap a dot inside a big square for a BOOM
- Pop, Blast and Shuffle power-ups, earned by playing
- Works offline once installed: open in Safari → Share → Add to Home Screen

Play: https://widdtom.github.io/pop-dots/

When you change any file, bump the cache name in `sw.js` (`popdots-v1` → `popdots-v2`) so installed copies update.
